# Bundled fonts

`SymbolsNerdFontMono-Regular.ttf` is copied unmodified from the Nerd Fonts
v3.5.1 release asset `NerdFontsSymbolsOnly.zip`
(https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1). Only the Mono
TTF is vendored. The font itself is MIT licensed; see `LICENSE` next to it.

Nice embeds it and registers it for its own process at launch, so powerline and
Nerd Font icon glyphs render with any terminal font
(https://github.com/Nick-Anderssohn/nice/issues/6). See
`docs/plans/nerd-font-fallback.md`.

The icon sets inside the font carry their own licenses. The table below is
