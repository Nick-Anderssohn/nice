  • done^⌘h/^⌘l prev/next pill and ^⌘j/^⌘k next/prev sidebar session; ^⌘⇧hjkl = directional pane focus, bound but inert until Phase 2 — hjkl ladder (2026-08-11 revision): ^⌘[/^⌘] and ⌘⌥↑/⌘⌥↓/⌘⌥←/⌘⌥→ all freed

  • done^⌘↑/^⌘↓ half-page scrollback (no-op on the alternate screen) — moved off ^⌘u/^⌘d 2026-08-11; both freed
  • doneHold-to-hint overlay — index badges on the pills after ~200 ms of held ^⌘ D5: modifier-observer only, binds no keys
  • doneGuard reserved combos in the recorder (^⌘Q ^⌘F ^⌘Space ^⌘D + the fixed accelerators + D4: ^⌘z ^⌘v ^⌘s ^⌘/, plus the ladder's ^⌥⌘hjkl resize and ^⌥⌘⇧hjkl swap rungs — 20 entries)
  • doneLive gate: the keybind-scheme self-test scenario (every chord asserted on its effect AND on zero pty bytes)

Phase 2 — splits

L

The core investment: a split tree inside each upper-bar pill. A pane is one leaf of that tree; a pill that is never split behaves exactly as before.

  • doneModel: binary layout tree per pill (PaneLayout — leaves = panes, splits carry orientation + ratio); active_pane_id = focused leaf
  • doneOne shared geometry — leaf_rects, directional_neighbor, spatial_refocus — used by render, focus, swap and close-refocus alike
  • doneWindowHostView: recursive mount, N mounted TerminalViews, accent-border focused-pane affordance first-render focus grab suppressed so a tree mounting in one pass can't hand focus to the last leaf
  • doneDivider drag-resize sidebar resize-handle pattern: cursor flip per orientation, root-level tracking, min clamp, double-click resets to half
  • donePane-keyed pty layer: multi-spawn per pill, per-pane exit/hold/title/cwd routing, OR-across-leaves status and busy-close gate event subscriptions retained and re-keyable, not permanently detached
  • doneActions on the ^⌘ ladder: ^⌘-/^⌘\ split down/right D2 divider mnemonics — ^⌘v/^⌘s freed instead, ^⌘z zoom, ^⌘b break-pane-to-pill, and the inert ^⌘⇧hjkl focus handlers filled in
  • doneClaim the reserved ladder rungs as real bindings: ^⌥⌘hjkl resize, ^⌥⌘⇧hjkl swap 12 new actions (22 → 34); RESERVED_COMBOS 20 → 9
  • doneSpatial close-refocus (shared-edge neighbor, not index neighbor)
  • donePersist layout in PersistedTermWindow optional layout/activeLeafId, written only for multi-pane pills; version stays 3, loader validates or falls back and never errors
  • doneLive gate: the splits self-test scenario (every pane verb asserted on its model effect AND on zero pty bytes)
  • deferredEven-layout presets (tmux select-layout) — D3: revisit once the tree exists and the need is felt

Phase 3 — copy mode & search

M

Keyboard-driven scrollback on top of alacritty primitives already linked. Per-pane: copy mode is TermMode::VI, and search is copy mode with a query (D1).

  • doneCopy-mode engine on TerminalSessionHandle: enter/exit/toggle, every ViMotion, g/G, half- and full-page paging P6 exit order — clear selection, clear search, scroll to bottom, VI off
  • doneKeyboard selection via the existing selection API: v/V/^v toggle char/line/block off a tracked anchor, motions extend it, y yanks and exits P5; ⌘C copies and stays in the mode
  • doneIn-mode key table plus the four extra gates P4: key-up release reports, the three IME callbacks, bare-modifier reports and mouse reporting are suspended too — on_key_down is not the only pty writer
  • done^⌘/ search field (the inline-rename editor, re-dressed) + RegexSearch over scrollback P7: backward by default, smart-case, wrapping; Esc closes the field and leaves you in copy mode
  • doneMatch highlighting in element.rs (a third SnapshotKey channel, recomputed per frame) + n/N over the full scrollback P8: tints derived from the selection colour and the caret accent, no new theme keys in v1
  • doneBlock vi cursor + a top-right COPY badge naming the live query P9: vi_mode_cursor_style pinned so a DECSCUSR beam can't hide the keyboard cursor
  • doneTwo rebindable actions — ^⌘c Copy Mode, ^⌘/ Search Scrollback 34 → 36 actions; RESERVED_COMBOS 9 → 8, spending its last FuturePhase entry
  • doneLive gate: the copy-mode self-test scenario (motions, paging, yank, search confirm and n/N asserted on their effect AND on zero pty bytes)
  • deferredMatch counter in the search field — P7: needs a full-scrollback walk per keystroke; revisit if its absence grates

Decisions (locked)

  • Held ^⌘ + vim keys, not a tmux-style prefix — no pending state, free OS key-repeat, zero pty collisions 2026-08-05
  • ^⌘[ / ^⌘] for prev/next pill (over ^⌘n/^⌘p) — superseded by the hjkl ladder below 2026-08-05
  • Hold-to-hint overlay is part of the scheme (live tmux display-panes) 2026-08-05
  • Upper-bar pill = tmux window; split tree lives inside a pill; pill strip stays linear 2026-08-05
  • Keystroke-sequence support deferred — only needed for a future tmux-compat prefix mode 2026-08-05
  • Detach = in-app first (session registry), full daemon deferred 2026-08-05
  • Code adopts tmux terminology before feature work (Phase R first): Tab→Session, Pane→TermWindow, split leaf = Pane; disk/wire names frozen 2026-08-07
  • TermWindow over qualified model::Window (no gpui::Window collision); Phase R includes the UI copy pass; plan at docs/plans/phase-r-terminology-rename.md 2026-08-08
  • Never bind: ^⌘Q (lock screen) ^⌘F (fullscreen) ^⌘Space (emoji) ^⌘D (dictionary)
  • D1 — ^⌘[/^⌘] become the PrevWindow/NextWindow defaults (frozen ids unchanged); ⌘⌥←/⌘⌥→ are freed, no dual-chord installs — chords revised by the hjkl ladder below; the ids-stay-frozen rule still holds 2026-08-11
  • D2 — ^⌘1-9 is ONE rebindable row (windowByIndex): the recorded modifier set applies to every digit; nine separate rows rejected 2026-08-11
  • D3 — the FocusPaneLeft/Down/Up/Right actions are named for their Phase 2 spatial meaning, so Phase 2 swaps handlers only — the ladder moved them to ^⌘⇧hjkl, where all four are inert; nothing aliases the pill strip any more 2026-08-11
  • D4 — the future-phase chords (^⌘z ^⌘v ^⌘s ^⌘/) go in the reserved-combo guard rather than shipping as no-op actions — Phase 2 claimed ^⌘z and the eight ladder rungs and freed ^⌘v/^⌘s, taking the table 20 → 9; Phase 3 then spent the last one, ^⌘/, taking it to 8 with no FuturePhase group left 2026-08-11
  • D5 — the hint overlay appears after ~200 ms of held ^⌘ and hides instantly on release or any change to the held set 2026-08-11
  • hjkl ladder (revises D1/D3 post-ship) — the modifier set selects the verb: bare ^⌘ navigates containers (h/l pills, j/k sessions), ^⌘⇧ moves pane focus, ^⌥⌘ resizes, ^⌥⌘⇧ (Hyper) swaps. Sessions join the bare layer; ^⌘Space for swap was rejected (macOS emoji picker, and Space is not a modifier). ^⌘[/^⌘] and the ⌘⌥ arrows are freed 2026-08-11
  • Half-page scroll moved to ^⌘↑/^⌘↓ — real ^⌘D keydowns are swallowed by the macOS dictionary hotkey before the app sees them (found in hand-testing; the gpui-level scenario injects downstream of the OS intercept and cannot detect it). ^⌘u/^⌘d are freed, and ^⌘D is a pure reserved entry again 2026-08-11
  • No shortcut-store migration for the D1 flip: a user who ever rebound anything keeps their stored combos and loads the new action ids unbound (frozen load rule 5) — accepted, not a bug 2026-08-11
  • Scrollback keys are Shift-variants only (⇧PageUp/⇧PageDown/⇧Home/⇧End); plain keys keep encoding to the pty; alt screen falls through to the TUI 2026-08-10
  • TERMINAL_MIN_WIDTH = 300pt; sidebar max = viewport − 300pt (fixed 480pt cap retired) 2026-08-10
  • Phase 2 D1 — any pill splits, and a new pane is always a plain shell in the focused pane's cwd. Nice never spawns Claude into a split pane, so the ≤1-running-Claude-per-session invariant is untouched; Claude in one pane with a shell beside it is the point 2026-08-12
  • Phase 2 D2 — split chords are divider mnemonics: ^⌘- splits down (stacked), ^⌘\ splits right (side by side). The words "vertical" and "horizontal" appear nowhere in UI, action names or ids — vim and tmux assign them opposite meanings. ^⌘v/^⌘s end bound to nothing 2026-08-12
  • Phase 2 D3 — scope is core plus break-pane (^⌘b); tmux select-layout even-layout presets deferred until the tree exists and the need is felt 2026-08-12
  • Pane identity stays off the frozen surfaces — pane ids are internal strings; every pane's pty keeps the pill's NICE_TAB_ID/NICE_PANE_ID, so paneId permanently means "pill" and socket traffic still routes there. Pane-level addressing waits for Phase 5 2026-08-12
  • Zoom is transient, focus does not wrap — zoomed is never persisted and any structural or focus change un-zooms first (tmux select-pane behavior); directional pane focus stops at the edges rather than wrapping or falling through to pill nav, since bare ^⌘h/^⌘l is how you leave the pill 2026-08-12
  • Accepted wart — after break-pane the moved pty's NICE_TAB_ID/NICE_PANE_ID still name the source pill (env is fixed at fork), so socket traffic from that shell targets the old pill. Same class of staleness as moving any live process 2026-08-12
  • Phase 3 D1 — one integrated mode: search is "copy mode with a query". Confirming a search jumps the keyboard cursor to the match and leaves you IN copy mode, so search → land → v → y is one flow. tmux's model 2026-08-13
  • Phase 3 D2 — ^⌘c enters copy mode directly, beside the other pane verbs. Accepted cost: it neighbours ⌘C copy, so a slipped Ctrl enters the mode instead of copying — Esc recovers 2026-08-13
  • Phase 3 D3 — the FULL vi key set, not a minimal one: the library models every motion, so the cost over a subset is key-table size, not machinery 2026-08-13
  • Copy mode is orthogonal to every Phase 2 gate (P10) — it never counts as busy, never blocks close, works on the alternate screen and on HELD panes (the copy gate runs before the held gate), and SUSPENDS mouse reporting so wheel/click/drag act locally, the way tmux captures the mouse in copy mode 2026-08-13
  • No match counter in v1 (P7) and no new theme keys (P8) — a counter needs a full-scrollback walk per keystroke, and the match tints derive from the selection colour and the caret accent. Both revisit at the feel-check 2026-08-13
