1

Client WindowState

The OS window. Many clients can exist; each shows one workspace of projects → sessions → windows.

2

Window TermWindow

One pill = one pty (a shell or a Claude run). Only one is visible per session; the rest keep running in the background. was: “pane” / top-bar tab

Menus say “Terminal Window” / “Claude Window” — ⌘N/⌘W still mean the OS window.

3

Window strip

The row of window pills for the active session. was: pane strip

4

Project

A sidebar group of sessions. Unchanged — tmux has no equivalent.

5

Session

One sidebar row: a named group of windows with one active. Handoffs/dispatches nest as child sessions. was: tab

6

Pane (reserved — Phase 2)

A split inside a window. Doesn't exist yet; the word is freed and waiting. Until then the terminal area shows the active window whole.

And the server is just the app process — no daemon; sessions survive window closes starting Phase 4, and app restarts via sessions.json restore. Keybinds: ^⌘[/^⌘] switch windows, ^⌘h/l switch panes (later), hold ^⌘ for hints.
