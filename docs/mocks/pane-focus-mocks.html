Focused-pane affordance — options

Every option below assumes the padding fix as baseline: in a split, each pane gets its own inner inset (~10–12px) so terminal content never touches a pane edge, divider, or indicator — mirroring the breathing room a single-pane pill already has. Left pane is the focused one in every mock. Zoom shows a single pane, so no affordance applies there.
